使用方法

  1. 选择路径

    拖入文件或文件夹。勾选「递归查询」即可扫描子文件夹中的文件。

  2. 检测占用

    查看 Windows Restart Manager 检测到的占用进程及其 PID。

  3. 关闭选中的程序

    可以先尝试「正常关闭」。「强制结束」可能导致未保存的数据丢失。
